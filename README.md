# Nature View 🌿
About the Project

Nature View is a simple and beautiful webpage created using HTML and CSS. It displays a nature background image with a heading and a short message about beautiful flowers.

# Technologies Used
HTML
CSS
# Features
Full-screen background image
Beautiful nature theme
White text with a transparent background
Simple and clean design
# Project Structure
index.html – Main webpage
Capture 1.PNG – Background image
# How to Run
Download or clone the project.
Keep the HTML file and background image in the same folder.
Open index.html in any web browser.
